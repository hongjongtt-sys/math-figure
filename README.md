# 수학 그림판

시험지·학습지에 넣을 수학 그림을 그리는 웹앱입니다. 로그인 없이 브라우저에서 바로 씁니다.

- 함수 그래프: 구간별 함수(●/○ 자동), 범위 제한 `y=2x (x<=2)`, 음함수, 극좌표, 매개변수, 부등식 영역, 두 곡선 사이 넓이
- 도형·작도: 의존 관계가 있는 동적 기하(점을 옮기면 따라 움직임), 내접·외접원, 대칭·이동·회전
- 입체·전개도, 확률 그림(주사위·주머니·카드·나무 그림), 대응도, 정규분포
- 내보내기: PNG(인쇄용 4배)·SVG·클립보드 복사(한글에 붙이기), A4 학습지 인쇄·PDF
- 저장: 이 브라우저(도면함) + **파일로 저장/파일 열기**(.json) — 수업 중 저장해 두고 다음 시간에 이어서 그리기
- 수식 키보드: π, θ, √, ≤ 같은 기호를 눌러서 넣기

## 구조
- `index.html` 하나로 동작합니다(CSS·JS 포함). 수식 글자는 MathJax 3.2.2(jsdelivr)를 씁니다.
- 저장 위치: localStorage `mfd_cur`(지금 그림), `mfd_lib`(도면함), `mfd_sheet`(A4 학습지), `mfd_grade`.
- 서버·Firebase를 쓰지 않습니다.
